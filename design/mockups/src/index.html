What stays the same on every screen

Quiet chromeNavigation sits on the grey ground; only the work is on white cards.

One accentBlue marks the selection and the one main action of a screen. Red and amber only for problems.

Lemmata's typeYoung Serif for page titles, IBM Plex Sans for the interface, IBM Plex Mono for code and paths.

egui-readySolid fills, 1 px lines, rounded corners and one soft shadow. No blur, no gradients.
