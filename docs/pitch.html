The app never runs sudo itself. It detects the OS and package manager, shows the exact command and opens a terminal. On macOS it links to MacTeX or offers brew install --cask mactex-no-gui; on Windows it links to the TeX Live installer. Plan

Stack

LayerChoiceWhy
ShellTauri 2Small binaries, Rust backend, uses the system webview. Electron would be 10× the size.
EditorCodeMirror 6Fast with large files, good LaTeX grammar, and a Yjs binding if collaboration comes later.
Languagetexlab (LSP)Completion for commands, labels and citations, plus diagnostics and a document outline. Bundled, since it's one small binary.
EngineSystem TeX Live via latexmkpdfLaTeX, XeLaTeX and LuaLaTeX selectable per project. latexmk handles reruns and bibliography passes.
TeX detectionown crateFinds TeX Live in PATH and known install folders, checks the version, and maps OS to the right install command.
PreviewPDF.js + SyncTeXRe-renders without losing scroll position. SyncTeX handles click-to-source both ways.
Log parsingown crateTurns TeX logs into structured errors with file, line, plain message and a fix, including which package to install for a missing .sty.
Historygit (gitoxide)Snapshots become commits. Projects stay usable with any git tool.

Shipping it publicly

PlatformChannelsNotes
DownloadsGitHub Releases, linked from lemmata.briggen.devThe app checks for updates at lemmata.briggen.dev, which then points to GitHub. If the repo ever moves, only that redirect changes, not every installed copy.
LinuxAUR, AppImage, .deb/.rpmFlathub is deferred: Flatpak can't see the host's TeX Live from inside its sandbox without flatpak-spawn --host.
macOSSigned, notarised .dmg; own Homebrew tapNeeds an Apple Developer account (99 USD/year) for signing. The main Homebrew cask list favours GitHub-hosted, well-known projects, so start with your own homebrew-tap repo.
WindowsMSI via wingetDetects TeX Live or MiKTeX; with MiKTeX, missing packages can install on the fly. Unsigned installers trigger SmartScreen warnings. A code-signing certificate costs money; SignPath offers a free one to open-source projects.

Roadmap

Weeks 1–2 · spike

Prove the loop

  • Tauri window, CodeMirror, latexmk compile on save
  • PDF.js preview that keeps its scroll position across recompiles
  • Exit test: edit to updated PDF in under 1.5 s on a 60-page thesis, on Linux, macOS and Windows
Weeks 3–4 · onboarding

TeX Live detection and setup

  • Detection across PATH and known install folders on all three OSes, plus MiKTeX on Windows
  • Install commands per distro, "Check again", choose folder manually
  • Missing-package prompts in the editor, with the matching distro package or tlmgr command
Weeks 5–10 · MVP

Usable every day

  • File tree, tabs, outline, texlab completion
  • SyncTeX both ways, readable error panel
  • Project library, templates, Overleaf .zip import
  • Git snapshots with a simple history view
Weeks 11–13 · release

Public 0.1

  • Signing, notarisation, auto-update through Tauri's updater
  • AUR, Homebrew tap and winget packages; homepage and docs on lemmata.briggen.dev
  • GPL-3.0 licence, contributing guide, issue templates, crash reporting that users opt into
After 0.1

Things Overleaf users miss

  • Bibliography manager, Zotero (Better BibTeX) sync
  • Local spell and grammar check with LanguageTool
  • Visual diff between snapshots; collaboration later if people ask

Main risks

RiskMitigation
Onboarding drop-offA multi-GB install is the biggest hurdle for new users. Lead with the smaller recommended set, show progress honestly, and let people browse templates while it installs.
Distro packagingDebian, Arch and Fedora split TeX Live into different packages. Keep the mapping in a data file that contributors can update without touching code.
Webview quirksWebKitGTK on Linux renders PDF.js more slowly. Benchmark it during the spike, before committing.
Old TeX LiveUbuntu LTS can ship a TeX Live that's two years old. Warn below a minimum year rather than refusing to run.
